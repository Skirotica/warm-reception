    Known limitations
    
            
    Scope decisions for this prototype — not a feature backlog apology.
    
            
      
              
    1. 
                Scope: Legaltech event-driven recruiting outreach only, drafting a Black Gavel 4-email sequence in English. Not an automated drip scheduler; only human-approved emails route to sandbox. Other sectors and languages are out of scope.
              
      2. 
              
    2. 
                Pre-qualified whitelist: Partner-vetted companies (Floating Legal, Cataract Legal LLC, Frame Em LLC, Plunge Inc.) skip ICP re-score and go to event + draft. Whitelist does not bypass client stop, missing email, entity collision, or disqualifying current-event signals.
              
      3. 
              
    3. 
                Throughput: The review queue is built for one case at a time. Run All is demo batching for the eval set, not production concurrency or a live partner inbox.
              
      4. 
              
    4. 
                Data contract: The agent only sees the embedded candidate events, company profiles, ICP contacts, pre-qualified whitelist, and company status in this file’s exact shape. Live CRM, ATS, or free-form paste is not supported.
              
      5. 
              
    5. 
                Lookups and send: Event research cites Exa.ai through the production API worker (no Exa key in this page). Public GitHub Live is synthetic only: Hunter, Exa refresh, and the partner store stay off. On private Live after Access login, Hunter can find company emails after Save API and Save code. Some non-US cases stay out of the real-email path until Chad accepts extra legal load. Partners can add a POC email in the human gate to move No-go → Go and generate Black Gavel. Capstone CE-08 at the site root still demos embedded missing-email rules. Nothing leaves without human Approve.
              
      6. 
              
    6. 
                Hard stops and POC coverage: Existing-client and entity-collision cases must refuse or escalate rather than auto-send. Private Live checks the partner client book in the private store (never outreach, no draft). Capstone demo checks embedded company_contacts (CE-08). Live public GitHub Pages does not run Hunter and does not load the client book. Private Live may run Hunter after Save API and Save code. Confirm never invents a person, an email, or a website from the company name. Real mailbox send stays locked until 75% of emails are approved without edit, on at least 32 reviewed emails.
              
      7. 
              
    7. 
                Review agent stretch: A second agent critiques the worker before the human gate (looks right / needs attention). It adds latency and token cost; the human still makes the final Approve / Edit / Escalate click.
              
      8. 
              
    8. 
                Voice memory: Chad (partner_c) and Nick (partner_n) each have separate edit-learned rules in this browser. Edits on a case train only that case’s partner. Memory is localStorage, not a shared production model.
